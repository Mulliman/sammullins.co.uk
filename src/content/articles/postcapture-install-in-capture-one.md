PostCapture adds borders and watermarks to photos, choosing which ones from each image's metadata. It works as a Capture One plugin as well as a standalone program. This is the first of a set of short videos.

## Install the plugin

1. In Capture One, open **Preferences** and go to the **Plugins** tab.
2. Use the button at the bottom left to install a plugin from a file, and choose the PostCapture `.coplugin` file.
3. PostCapture now appears in the plugin list. Select it to see its settings, including **Open Configuration** and the path to the post process program.

That's it. Next, [create your first process](/articles/postcapture-create-your-first-process/).

Download PostCapture from the [GitHub page](https://mulliman.github.io/PostCapture/).
