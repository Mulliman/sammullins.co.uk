PanoCapture is a free, open source plugin for Capture One that creates panoramas from several photos. It uses [Hugin](https://hugin.sourceforge.io/), an open source panorama stitcher, to do the stitching, so you don't have to leave Capture One to make one.

This short video shows installing the plugin in Capture One and then stitching a panorama with it.

Find out more and download it from the [PanoCapture GitHub page](https://mulliman.github.io/PanoCapture/).
