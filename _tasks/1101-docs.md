## Scope

- `README.md`:
  - what this is, with a screenshot
  - badges: CI, Scorecard, licence
  - quick start
  - architecture diagram (Mermaid)
  - a "How AI writes this site" section covering AGENTS.md, skills, the PR gate and "Sam merges"
  - a link to `_tasks/`
- `ARCHITECTURE.md`: absorbs `_docs/audit-2026-11.md` §3–4 and the content model; keep it up to date.
- `SECURITY.md`: scope (static site), how to report (GitHub private vulnerability reporting), what's in and out.
- `CONTRIBUTING.md`: issues welcome; **content PRs not accepted**; code PRs by discussion only.
- **Licensing split:**
  - `LICENSE`: MIT, covering code only
  - `LICENSE-CONTENT.md` / `NOTICE`: "All content (text, images, photographs, CV) © Sam Mullins. All rights reserved." plus the paths it covers (`src/content/**`, `src/assets/media/**`, `public/media/**`)
  - a short notice file inside the content folders
  - third-party licences for fonts and any vendored script
- `CODE_OF_CONDUCT.md` (optional; a short Contributor Covenant reference).
