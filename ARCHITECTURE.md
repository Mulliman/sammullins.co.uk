# Architecture

Short version. The reasoning is in [`_docs/decisions.md`](_docs/decisions.md) and the options comparison in [`_docs/audit-2026-11.md`](_docs/audit-2026-11.md) §3.

## Stack

- **Astro 7**, static output, `trailingSlash: 'always'`, directory format. URLs are identical to the 2021 Umbraco/xStatic site.
- **Content Layer** collections (`pages`, `articles`, `software`, `albums`, plus `settings` and `redirects` data) validated by **Zod** in `src/content.config.ts`. A page is front matter plus `blocks: [...]` (a discriminated union on `type`) plus an optional Markdown body placed by a `body` block.
- **Rendering:** `src/components/Blocks.astro` maps each block type to `src/blocks/*.astro` with an exhaustive `switch` (a new type without a component is a type error). `EntryPage.astro` wraps any entry with the layout, archive banner, series nav, colophon and agent view.
- **Markdown:**
  - long-form bodies use Astro's native pipeline with Prism (class-based, so CSP-safe; Shiki's inline styles aren't)
  - short strings inside blocks use `marked` with raw HTML escaped
- **Images:** AVIF masters in `src/assets/media`, output as responsive AVIF + WebP via `<Pic>` (`astro:assets`). Legacy `/media/...` URLs are 301'd to stable copies by `integrations/site-files.mjs`.
- **No framework JS:** no React or UIkit. A few small bundled scripts (theme toggle, gallery lightbox, embed facade, agent view, console secret, signature), each a progressive enhancement.

## Security model

| Layer           | Control                                                                                                                                                                                                              |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime surface | Static files only. No Functions, Forms or Identity on Netlify.                                                                                                                                                       |
| Browser         | `<meta>` CSP generated by Astro with sha256 hashes: `default-src 'self'`; plus a header CSP with `frame-ancestors 'none'`, HSTS preload, nosniff, COOP/CORP, a locked Permissions-Policy (`netlify.toml`)            |
| Third parties   | None at load. YouTube only after a click (nocookie). Analytics: self-hosted GoatCounter script, off until configured.                                                                                                |
| Supply chain    | Small direct dependency list; pnpm `minimumReleaseAge: 10080`; install scripts only for sharp and esbuild; exact versions; Renovate with a 7-day cooldown and no automerge; Actions pinned by SHA; CodeQL; Scorecard |
| Content         | Schema validation; block Markdown escapes HTML; `set:html` is only allowed with sanitised helpers (enforced by a test)                                                                                               |
| Process         | Branch → PR → CI → preview → **Sam merges**. Nothing auto-merges or auto-publishes.                                                                                                                                  |

## Quality gates (CI)

`astro check` · Prettier · the skills catalogue and mirror are up to date · build (schema + redirect validation) · unit tests (50 legacy URLs, 306 media paths, hygiene: no gmail/GA/Google Fonts/UIkit/inline styles, CSP on every page, Markdown twin for every page, alt on every image) · lychee internal links · axe WCAG 2.2 AA on every page in light and dark plus 320px overflow · CodeQL · Scorecard · PR-title convention.
