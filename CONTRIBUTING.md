# Contributing

Thanks for looking! This is a personal website, so:

- **Issues are welcome**: broken links, accessibility problems, typos, bugs, ideas.
- **Content PRs are not accepted.** The words and pictures are mine (see `LICENSE-CONTENT.md`).
- **Code PRs** by discussion first, please: open an issue describing the change.

The repo is built largely with AI agents working from tickets in `_tasks/`. If you're curious how, start with `AGENTS.md`.
