## What counts as content

Content lives mainly in these paths:

- `src/content/**`: pages, articles, notes, software docs and photo albums
- `src/assets/media/**`: photographs and images
- `src/assets/brand/**`: the Sam Mullins logo
- `src/data/site.yaml`: the site's own copy (footer text and similar). The structure of the file is code; the words in it are content.
- `public/humans.txt`
- `public/media/**` (if present)
- `_docs/decisions.md`, `_docs/voice.md`, `_docs/voice-sources.md`: my planning notes and writing-voice guide

Wherever else they appear (for example a sentence of page copy inside an `.astro` file), the words, pictures and other creative material shown on the website are content. If in doubt, assume something you can see or read on www.sammullins.co.uk is content, and the code that builds and displays it is MIT.
